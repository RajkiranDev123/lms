Developed a full-stack MERN application designed to manage library operations, including book inventory, user 
registration, and a streamlined borrowing and return process. Features role-based access for admins and user,
secure authentication, and automation of borrowed books reminders to improve efficiency and accuracy.

Features and Implementations :
Robust & Optimized backend API's, Fully responsive, Promise.all for initiating multiple requests at once,  Material UI & Tailwind CSS, Debouncing, Role-based access (Admin, Student), book issue/return flow, fine calculation for overdue returns,
Admin and Student dashboard with statistics, cron jobs for overdue and optimized backend logic.


Tech Stack : React.js, Tailwind CSS, Node.js, Express.js, MongoDB, Material UI, Redux Toolkit.
